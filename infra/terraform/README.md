# Laboratório AWS com Terraform

Este diretório está reservado para a infraestrutura do laboratório. Ele não
contém recursos aplicáveis enquanto o Gate A local não estiver concluído.

O primeiro módulo deverá ser pequeno, removível e documentado. A proposta
inicial é avaliar S3 privado, IAM de menor privilégio, federação OIDC para o
GitHub e logs. O executor e o agendamento serão escolhidos somente após medir
tempo, memória, dependências e volume dos pilotos SINAN e SINESP.

Nunca armazenar credenciais, state com segredos ou identificadores sensíveis no
repositório.
