# Referências visuais do atlas

## Referência 1

Arquivo: `referencia-01-bi-claro.png`

Selecionada em 2026-10-29. A direção aprovada combina a disposição analítica
da proposta escura com uma paleta clara e institucional. Elementos centrais:

- comparação simultânea de Brasil, Santa Catarina e município;
- série histórica ampla com taxas e números absolutos;
- mapa municipal integrado à mesma tela;
- blocos inferiores para idade, ranking territorial e qualidade do dado;
- fundo marfim, azul petróleo, cinzas e uso pontual de vinho;
- módulos alinhados por uma grade comum, sem excesso de cartões arredondados.

É uma referência de linguagem e estrutura. Ainda não foi aplicada ao site.
